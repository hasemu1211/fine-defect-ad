# 동일 이미지의 이상 맵 비교 분석

이 문서는 **같은 결함 이미지에서 EfficientAD E2-Split과 SuperADD가 어디를 다르게 탐지했는지**, 그리고 그 차이가 결함 크기·형상과 어떤 관계가 있었는지 설명합니다.

## 핵심 요약

전체 AU-PRO는 “어느 파이프라인의 평균 위치화 점수가 높은가”만 보여 줍니다. 이 분석은 정답 마스크가 있는 **동일 불량 이미지 90장**을 일대일로 비교해 성능 차이가 발생한 조건을 분해했습니다.

- SuperADD의 위치화 우위는 모든 이미지에 균일하지 않았습니다.
- `SuperADD − E2-Split` pixel AU-ROC 차이는 결함 면적이 낮음 `+0.091`, 중간 `+0.206`, 높음 `+0.070`이었습니다.
- 차이는 **중간 크기 결함에서 가장 크게** 관측됐습니다.
- Compactness와 성능 차이의 Spearman 상관은 `-0.773`이었습니다. 덜 compact한 형상에서 SuperADD 우위가 커지는 경향이 관측됐습니다.
- 개별 사례에는 E2-Split 우세 `-0.156`, 거의 동일 `-0.003`, SuperADD 우세 `+0.412`가 모두 존재했습니다.

따라서 이 분석의 가치는 “SuperADD 점수가 더 높다”는 반복이 아니라, **집계 성능 차이를 결함 조건별 오류 패턴으로 설명하고 다음 개선 가설을 만들 수 있게 한 것**입니다.

## 이 분석이 필요한 이유

Image AU-ROC와 AU-PRO는 데이터셋 전체를 하나의 숫자로 요약합니다. 그러나 그 숫자만으로는 작은 결함, 복잡한 경계, 특정 위치의 결함 중 어디에서 차이가 생겼는지 알 수 없습니다.

같은 이미지와 같은 정답 마스크를 두 파이프라인에 짝지으면 이미지 난이도 차이를 줄이고 다음 질문을 확인할 수 있습니다.

> 두 파이프라인의 위치화 차이는 어떤 결함 크기와 형상에서 커지는가?

## 관측 결과

![결함 면적 구간별 paired pixel AU-ROC 차이](assets/paired-rawmap-analysis.svg)

| 결함 면적 구간 | 이미지 수 | 평균 pixel AU-ROC 차이(SuperADD−E2) | 해석 |
| --- | ---: | ---: | --- |
| 낮음 | 30 | +0.091 | SuperADD가 평균적으로 우세 |
| 중간 | 30 | **+0.206** | 두 경로의 차이가 가장 큼 |
| 높음 | 30 | +0.070 | 차이가 상대적으로 감소 |

Compactness는 결함이 얼마나 둥글고 조밀한지를 나타냅니다. 값이 낮을수록 경계가 복잡하거나 덜 조밀한 형상입니다. 관측된 음의 상관 `-0.773`은 compactness가 낮아질수록 SuperADD의 상대적 위치화 성능이 커지는 경향을 나타냅니다.

이 분석은 고정된 이상 맵의 기술 통계입니다. 구조적 원인 검증에는 특징 표현을 통제한 대조 실험이 필요합니다.

## 대표 이상 맵 패널

![익명 이상 맵과 정답 마스크 패널](assets/paired-rawmap-panel.png)

### 패널 읽는 법

- 왼쪽은 E2-Split 이상 맵, 가운데는 SuperADD 이상 맵, 오른쪽은 정답 결함 마스크입니다.
- 이상 맵은 **검정색일수록 높은 이상 점수**, 흰색일수록 낮은 점수입니다.
- 정답 마스크의 흰색 픽셀이 실제 결함 영역입니다.
- `ΔAUROC`는 `SuperADD − E2-Split`입니다. 음수는 E2-Split 우세, 0 근처는 유사, 양수는 SuperADD 우세를 뜻합니다.

### 세 사례 해석

| 사례 | 관측 | 해석 |
| --- | --- | --- |
| **E2-Split 우세 사례** `-0.1555` | 오른쪽 가장자리에 연결된 넓은 결함과 작은 결함이 함께 존재 | E2-Split이 해당 이미지의 결함 픽셀을 정상 픽셀보다 더 잘 순위화했습니다. 넓거나 가장자리에 연결된 결함에서 유리했던 사례입니다. |
| **거의 동일한 사례** `-0.0029` | 정답 결함이 매우 작은 점 형태 | 두 경로 모두 표면 질감에 넓게 반응했고 결함 픽셀 순위 차이가 거의 없었습니다. |
| **SuperADD 우세 사례** `+0.4120` | 중앙 부근에 가늘고 불규칙한 선형 결함이 존재 | SuperADD 이상 맵의 선형 반응이 정답 마스크 방향과 더 잘 맞았습니다. 낮은 compactness에서 차이가 커진 전체 통계와 같은 경향입니다. |

세 이미지는 전체 결과를 대신하는 표본이 아니라, 실제로 관측된 `E2-Split 우세`, `유사`, `SuperADD 우세` 조건을 보여 주는 대표 사례입니다.

### 밝기 정규화 방식

현재 패널은 각 이미지·파이프라인 내부에서 독립적인 min–max 정규화를 사용합니다. 이 방식은 **한 이상 맵 안에서 어느 위치를 강하게 본 것인지** 확인하기 쉽지만, 모델 간 흑백 밝기의 절대 크기는 비교할 수 없습니다. 극단값 하나가 전체 대비를 바꿀 수도 있습니다.

두 TEST 맵을 하나의 평균·분산으로 정규화하면 모델별 원시 점수 척도와 TEST 데이터 분포가 섞입니다. 비교용 시각화에는 다음 절차가 더 적합합니다.

1. 모델별 **검증 정상 점수 분포**를 평가 전에 고정합니다.
2. 각 픽셀 점수를 해당 정상 분포의 백분위로 변환합니다.
3. 두 모델 모두 같은 `0~1` 백분위 색상표로 표시합니다.

이 화면에서 같은 밝기는 “각 모델의 정상 분포에서 비슷하게 이례적인 점수”라는 의미가 됩니다. 원시 이상 맵과 Image AU-ROC/AU-PRO 계산은 변경하지 않고 시각화 산출물만 별도로 생성할 수 있습니다.

현재 공개 증거에는 SuperADD 검증 정상 맵의 해시와 재구성 기록은 있지만 비교 화면을 만들 원시 검증 맵 바이트는 포함되어 있지 않습니다. 따라서 현재 패널을 PNG에서 다시 정규화하지 않습니다. 원시 검증 맵을 다시 확보할 때 백분위 화면을 별도 산출물로 생성하는 방식이 데이터 손실 없이 재현 가능한 경로입니다.

## 분석 방법

### 입력과 무결성 확인

- MVTec AD 2 Sheet-Metal TESTpub의 동일한 불량 이미지 90장
- 파이프라인별 528×2112 FP32 이상 맵
- 같은 이미지의 정답 결함 마스크
- 익명 이미지 ID와 원본·마스크·이상 맵 SHA-256

분석 전에 두 파이프라인의 이미지 순서, shape, dtype와 모든 해시를 다시 확인합니다. 원본 제조 이미지는 시각자료에 사용하지 않습니다.

### 계산

1. 이미지마다 이상 맵과 정답 마스크로 동점 점수를 처리하는 pixel AU-ROC를 계산합니다.
2. `SuperADD − E2-Split` 차이를 구합니다.
3. 정답 마스크에서 결함 면적 비율, 테두리 거리, 길쭉함, compactness를 계산합니다.
4. 결함 면적을 데이터셋 내부의 낮음·중간·높음 세 구간으로 나눠 평균 차이를 집계합니다.
5. 형상 지표와 성능 차이의 Spearman 순위 상관을 계산합니다.

Compactness는 4방향 디지털 둘레 `P`와 면적 `A`를 이용한 `4πA/P²`입니다. 구간 경계는 이 데이터셋 내부에서 계산한 기술 통계입니다.

## 해석 한계

- 결과는 정답 결함 마스크가 있는 불량 이미지 90장에 한정됩니다.
- 관측된 연관성의 범위는 고정된 불량 이미지 90장입니다. 인과 검증과 다른 데이터셋 비교는 별도 실험 범위입니다.
- 파이프라인마다 점수 척도가 달라 원시 점수 크기를 직접 비교하지 않고 각 맵 내부의 픽셀 순위만 사용합니다.
- 원본 이미지가 공개되지 않으므로 패널은 표면 맥락이 아니라 위치화 차이를 보여 줍니다.

전체 평가 규약과 집계 지표는 [평가 방법](EVALUATION.md), 데이터 공개 범위는 [한계](LIMITATIONS.md)에 있습니다.
